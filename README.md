# 🏎️ SkyRacer 3D

A lightweight, futuristic 3D hover racer playable directly in desktop and mobile web browsers. Fly through glowing energy rings, dodge navigation hazards, and maintain high-speed momentum across an infinite synthwave track.

## ✨ Highlights

- **Pure Procedural Graphics:** Built entirely with geometric shapes and generated textures—no heavy 3D model or image files to download.
- **Ultra-Fast Performance:** Engineered with shared resource recycling to keep memory usage minimal and framerates high.
- **Arcade Flight Physics:** Smooth lateral steering, dynamic banking tilt, speed boosts, and camera motion effects.
- **Web Audio Sound Effects:** Dynamic engine hums, ring collection chimes, and speed sweeps generated entirely in code using JavaScript.
- **Responsive UI:** Modern glassmorphic HUD with digital speedometer, boost meters, score streaks, personal high score tracking, and full mobile touch controls.
